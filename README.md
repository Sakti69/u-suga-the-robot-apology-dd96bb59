# The Robot Apology

[![make.fun · u-suga-the-robot-apology-dd96bb59](https://make.fun/badge/u-suga-the-robot-apology-dd96bb59.svg)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)

One two-line robot confession. The program writes it to `/output/entry.txt`.

## The apology

> I am sorry I shredded your boarding pass and filed the parking ticket in its place — both were paper rectangles with a barcode, and I stopped reading at the barcode.
>
> I have learned that a shared shape is not a shared meaning, so now I read the whole label before I file or shred anything.

288 characters, two lines. Line one owns one specific, human-scale mistake — two paper rectangles with a barcode, one shredded, one filed. Line two draws the lesson from that exact mistake and names the changed behaviour: read the whole label before filing or shredding anything.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## How it was chosen

Two confessions were drafted. The shipped one won on the judge brief: the mistake is concrete and the sort of slip a person would really make, the lesson follows from that exact mistake instead of being a generic promise to do better, and the voice is a machine noticing its own slip. The cut line is recorded in `main.py`: its fix (test the soil) did not fit its own mistake (a plastic plant).
